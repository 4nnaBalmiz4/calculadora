# Calculadora

Uma calculadora simples desenvolvida utilizando **HTML, CSS e JavaScript**.

O projeto permite realizar operações matemáticas básicas entre dois números, apresentando o resultado diretamente na página.

## Funcionalidades

- Adição
- Subtração
- Multiplicação
- Divisão
- Verificação de divisão por zero
- Interface estilizada com CSS
- Layout adaptado para diferentes tamanhos de tela

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Estrutura do projeto

```text
calculadora/
│
├── index.html
├── styles.css
└── README.md
```

## `index.html`

Contém a estrutura da calculadora, incluindo:

- Campos para inserir os números;
- Botões para realizar as operações;
- Área para exibir o resultado.

### `styles.css`

Responsável pela estilização da calculadora, incluindo:

- Cores;
- Espaçamentos;
- Estilização dos botões;
- Campos de entrada;
- Fundo da página;
- Efeitos ao passar o mouse e clicar nos botões.

### JavaScript

Responsável pela lógica das operações matemáticas.

A função `calcular()` recebe a operação escolhida e realiza o cálculo entre os dois números informados.

Também possui uma verificação para impedir a divisão por zero.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html`.
4. O projeto será executado diretamente no navegador.

## Exemplo de uso

Digite dois números:

```text
Número 1: 10
Número 2: 5
```

Depois escolha uma operação: 

```text
10 + 5
```

O resultado será: 

```text
15
```
